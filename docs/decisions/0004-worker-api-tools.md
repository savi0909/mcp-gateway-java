# 0004 - Add coordinator APIs alongside the payment MCP tool

Date: 2026-10-07. Status: implemented; compiled and SDK discovery checked;
automated test execution remains deferred.

The user requested worker APIs as tools and definitions. This supersedes the
single-tool/no-business-arguments boundary of the original milestone and ADR
0003. Include acquire, renew and release and their six namespace registration and
lookup prerequisites, inspected in the unchanged coordinator source. Keep one
fixed MCP endpoint and the existing REST contracts.

Introduce catalog version 3 with 1–32 uniquely named tools in one server. Keep
versions 1/2 single-tool and preserve their catalog files. Load immutable schemas
and bindings once and register an ASYNC SDK specification per tool with the
resolved SDK 2.0.0 APIs. Validate a small flat-object schema subset on input and
public response projection. Explicitly map arguments to body fields or complete
safe path segments; never accept client-selected URLs, headers or credentials.
Support the narrow string/number union for serialized lease duration. Preserve
integral numbers and return all advertised lease fields, omitting other backend
fields. Caller-supplied owner UUIDs are never generated by the gateway.

Add the optional deployment backend `payment-api`, so worker and payment tools
have distinct origins and tokens. `workers` exposes nine coordinator tools and
`worker-payments` exposes all ten. Default MCP remains disabled; `payments`
retains its original behavior. Do not combine `payments` and `worker-payments`.

Keep ADR 0002's user-authorized application retries within the shared deadline,
reusing exact invocation values. Connector retries, redirects and allocation
caching stay disabled. Failure text now names the backend and unknown operation
outcome, covering reads, registration, leases and payments. SDK execution errors
remain sanitized and omit structured content.

Evidence: Wrapper `verify -DskipTests` compiled source/tests and packaged the JAR,
skipping both test runners. Actual SDK discovery against a running combined
profile negotiated `2025-11-25` and listed all ten tools. The local gateway was
restarted to expose the definitions. No new worker/payment mutation was invoked.
Mock-backed catalog/protocol tests compile but await execution when tests resume.
Discovery does not establish worker execution, retry recovery or full milestone
acceptance.
